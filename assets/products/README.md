## Maintenance guidance

- Do not remove attribution for `zucchini-muffins.jpg`; its CC BY 2.0 licence requires it.
- Keep source links when replacing or editing an image, and note meaningful modifications.
- Prefer descriptive, lowercase filenames separated with hyphens.
- Optimize new images for web delivery and avoid committing unnecessarily large originals.
- Confirm that a new image's licence permits use on a commercial bakery website.
